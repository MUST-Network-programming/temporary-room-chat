# Collapsible Navigation Implementation Plan

**Goal:** 让左侧房间导航像 Codex 一样收起，聊天区与输入框自动占用释放的空间。

**Architecture:** 保留现有 HTML/CSS/JavaScript。桌面使用单列/双列布局切换，并保存本机折叠偏好；680px 及以下使用默认关闭的侧边抽屉，不覆盖桌面偏好。按钮沿用现有 SVG 和黑白主题。

**Tech Stack:** 原生 HTML/CSS/JavaScript、jsdom、C TCP/WebSocket 本地服务。

## 已确认的设计与约束

- 左上角始终可找到侧栏开关；登录页不显示房间导航开关。
- 桌面首次展开，收起后导航完全隐藏，刷新保持状态。
- 手机首次和刷新均收起，展开显示完整的房间名称、搜索和加入入口。
- 手机抽屉可通过关闭按钮、背景和 Escape 关闭；焦点返回开关，抽屉打开时键盘焦点不进入后面的聊天区。
- 手机选择最近房间或加入入口后收起，不改变当前房间和消息草稿。
- 折叠不改变账号、聊天协议、通知、邮件配置或右侧面板行为。
