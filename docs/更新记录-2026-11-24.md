## 使用部署包升级

将部署包上传到 Ubuntu 的 `/home/ubuntu/`，解压后进入对应版本目录，执行以下命令。

```sh
sudo bash scripts/upgrade-cloud.sh
```

脚本按 `REVISION` 校验版本，先完成编译和 CTest，再备份现有数据库与服务配置并切换服务。连接会在服务重启时断开。有效的持久化房间可重新加入。旧版内存房间无法导入数据库。

此脚本用于当前腾讯云实例的既有 systemd 部署。切换或验证失败时，脚本尝试恢复上一版服务，并显示备份位置。
