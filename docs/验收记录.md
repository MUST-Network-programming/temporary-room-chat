## 已修复的联调问题

- 测试启动等待由固定睡眠改为端口 readiness 检查，避免首次启动较慢造成误报。
- Windows 中文资源路径转换到 UTF-16 后使用 _wfopen。
- TLS 写等待期间只监听所需 readiness，避免无进展空转。
- 旧浏览器收到 session_replaced 后清空恢复身份，防止两个连接反复抢占同一会话。
