# 临时房间安全聊天系统实施计划

目标为 C11 Socket/select 服务端、浏览器客户端和可选 TLS，按五个原目录交付。

- [x] server：跨平台 socket、非阻塞事件循环、发送队列、断开通知。连接数 64，输入 32 KiB，输出 128 KiB，慢客户端超限断开。
- [x] websocket：HTTP 升级、掩码/长度/控制帧/UTF-8 校验、分片消息；JSON 编解码采用随项目提供的 cJSON。
- [x] rooms：16 个内存房间、6 位随机加入码、昵称最多 48 UTF-8 字节、正文最多 2048 字节、默认 3600 秒到期、随机令牌恢复成员及房主身份。
- [x] web：静态网页、心跳与重连，按协议联调；中文界面。
- [x] tls：OpenSSL 非阻塞握手及 WANT_READ/WANT_WRITE，证书生成和验证。
- [x] 集成：CMake、自动协议测试、真实浏览器验证、中文运行与演示资料。

接口以 include/chat.h 为准。消息 type 为 create/join/chat/leave/close/ping。
create {nickname}、join {room,nickname,token?}、chat {text}。
服务器 joined {room,nickname,token,owner,expires}、members {members:[昵称]}、chat {nickname,text}、closed {reason}、pong、error {code,message}。
只有有效会话令牌能恢复身份。断开保留成员会话到房间到期，离开则撤销令牌。房主离开关闭房间。

验证先检查缺失服务端的失败，再构建并运行真实 socket 测试。测试覆盖房间隔离、恢复、非法帧、部分读取、断开、关闭、到期与证书验证。Windows 无环境时交付精确步骤和待实测记录。

实际完成范围与需外部环境验证项目以 [[验收记录]] 为准。
