# 邮箱验证码登录

在登录页填写邮箱，点击「发送验证码」，然后在同一页面输入邮箱里收到的六位验证码。首次验证会创建账号，后续验证会登录同一个账号。新账号的房间昵称由系统分配，成员列表不会显示登录邮箱。

## 老账号怎么迁移

- 已通过邮箱验证注册的成员可以直接用原邮箱登录，房间身份随原账号保留。
- 只有旧用户名和密码的成员先点击「迁移未绑定邮箱的旧账号」，再填写旧凭据和新邮箱验证码。迁移完成后，下次只需邮箱验证码。
- 旧通知邮箱可用于迁移。请先通过迁移入口完成绑定，再用常规入口登录。同一个邮箱只能关联一个账号。
- 登录后可在「通知邮箱」主动选择「使用已验证的登录邮箱」，以接收重要通知。

## 本地验证

生成并信任本地预览证书，装好依赖后运行以下命令。

```sh
./scripts/preview-v2.sh --accounts
```

在 `https://127.0.0.1:8090` 使用 `person@example.test` 登录，到 `http://127.0.0.1:8025` 查看验证码。测试邮件由本地 SMTP 收件箱接收。

## 生产配置

1. 保留现有账号数据库。Python 网关的 `ACCOUNTS_DB` 与 C 服务的 `--accounts` 指向同一文件。
2. 使用现有 SMTP 配置，并在网关环境设置 `ALLOW_EXTERNAL_EMAIL=1`。登录验证码、通知邮箱验证和重要通知共用发件配置。具体参数见 [环境变量示例](../.env.example)。
3. 将 `/api/login/code` 与 `/ws` 接到同源 HTTPS 入口。网关经 WSS 连接 C 服务。反向代理用连接对端覆盖 `X-Real-IP`，配置示例见 [Nginx 配置](nginx-v2.conf.example)。
4. 上线后使用测试邮箱验证收件、刷新后的登录和原账号的房间权限。

验证码默认 5 分钟有效，最多尝试 5 次。同一邮箱默认 60 秒后可以重发，发信同时按邮箱和 IP 限流。邮件只包含验证码，验证码和浏览器收到的随机请求标识共同用于验证。C 服务在同一数据库事务中更新账号并核销验证码，然后签发聊天会话令牌。
