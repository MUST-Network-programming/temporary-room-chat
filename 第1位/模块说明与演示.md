# 第1位 · C 服务端与并发

`server.c` 是程序入口，`platform.h` 集中处理 POSIX 与 Winsock 差异。每个 Client 保存文件描述符、输入输出缓冲、WebSocket 状态及 TLS 状态。

## 为什么一个线程可以服务多人

`select` 告诉程序哪些 socket 当前可读或可写。程序只处理就绪连接，然后回到循环。所有 socket 都是非阻塞的，一个客户端暂时没数据时不会卡住其他人。

`recv` 一次可能只收到消息的一部分，先追加输入缓冲再交给 HTTP/WebSocket 解析。`send` 可能只发送一部分，`output_sent` 保存进度。缓冲上限限制慢客户端占用的内存，超限时清理连接。

TLS 写操作如果要求重试，必须保留指针、内容和长度。`pending_write` 保存本次写长度，新消息只追加到队尾。整批发送完毕才复位缓冲。

Windows 先调用 WSAStartup，句柄类型为 SOCKET，关闭用 closesocket，错误码来自 WSAGetLastError。POSIX 使用 int、close、errno。Windows select 忽略第一个参数，POSIX 要传最大 fd 加一。Windows FD_SETSIZE 设置为 128，以容纳 64 客户端和监听 socket，POSIX 接收时检查 fd 未超过集合范围。

## 答辩要点

非阻塞不等于每次都成功，EWOULDBLOCK 表示稍后再试。select 是就绪通知，应用仍需处理部分读写。HTTP/TLS 建连限时 10 秒，已连接客户端 60 秒无输入会清理。浏览器通过应用层心跳维持正常会话。
